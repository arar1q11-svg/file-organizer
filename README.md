# 파일정리 도우미

사진, 동영상, 음악, 문서, 압축 파일, 코드 등을 종류별 폴더에 담아 ZIP 파일로 내려받는 한국어 웹앱입니다.

## 사용하기

1. 웹페이지에서 파일을 선택하거나 정리 영역에 끌어다 놓습니다.
2. 자동으로 분류된 파일과 전체 용량을 확인합니다.
3. **파일 정리하고 ZIP 받기**를 누르면 분류별 폴더가 포함된 ZIP 파일을 저장합니다.

원본 파일은 옮기거나 삭제하지 않습니다. 파일 선택과 ZIP 생성은 브라우저 안에서만 처리하며 서버로 전송하지 않습니다. 한 번에 정리할 수 있는 파일 크기의 합은 250MB입니다.

## 로컬 개발

```sh
npm ci
npm run dev
```

프로덕션 빌드와 테스트:

```sh
npm test
npm run build
```

## 공개 배포

GitHub 저장소의 `main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 테스트와 빌드를 수행하고 GitHub Pages에 배포합니다. Pages 설정에서 빌드 및 배포 소스를 **GitHub Actions**로 지정해야 합니다.

사이트가 공개된 뒤 Google 검색 결과에 나타나기까지는 시간이 걸릴 수 있으며, 검색 노출은 Google이 결정하므로 보장되지 않습니다. `public/robots.txt`와 `public/sitemap.xml`이 제공됩니다. 더 빠른 색인 요청은 Google Search Console에서 사이트 소유권을 확인한 뒤 사이트맵을 제출하세요.
